# Maquette de l'administration simplifiée

Maquette validée par Christophe le 22 novembre 2026, à l'origine de la refonte
de l'administration du même jour. Une page HTML autonome : l'ouvrir dans un
navigateur suffit. Le menu, les onglets et les boutons sont cliquables, et la
barre du haut bascule entre ordinateur et mobile 390 px. Les données sont
fictives.

**Référence de rendu, pas source de vérité.** Là où elle diffère d'un ADR ou du
code livré, ceux-ci l'emportent. Ce qu'elle montre et que la refonte n'a pas
livré tel quel :

- **la recherche globale du bandeau** : la palette « Aller à… » reste, et la
  recherche se fait dans chaque liste ;
- **la fiche produit en un seul formulaire** avec un bouton « Enregistrer »
  fixe : chaque bloc garde son enregistrement ;
- **la barre d'onglets en bas de l'écran mobile** : le menu reste le panneau
  replié sous « Menu » ;
- **les commandes en cinq onglets** : les filtres de statut restent ceux de
  l'écran, renommés ;
- **la frise d'étapes des retours** : les statuts sont renommés, les gestes
  restent ceux de chaque demande.

L'analyse qui l'a précédée, écran par écran, est résumée sous la maquette.
